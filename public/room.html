On air · 0 te assistindo

Só a aba / janela (recomendado): o som do resto do PC (Discord, música…) não vai junto. Escolha uma aba do Chrome para levar o som dela. Janela de app leva o som só se o seu Chrome já suportar áudio de janela; tela inteira vai sem som.

Dispositivo de entrada: manda o áudio de um microfone ou de um cabo virtual. Para isolar o som de um jogo/app no Windows: instale o VB-Audio Virtual Cable → Configurações → Sistema → Som → Mixer de volume → no app desejado, mude a saída para CABLE Input → aqui, escolha CABLE Output.

Sistema inteiro: leva TODO o som do PC, inclusive o Discord, e seus amigos se ouvem de volta (eco). Evite em chamada.
